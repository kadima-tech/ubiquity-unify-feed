# Security Policy

## Reporting a Vulnerability

Report security vulnerabilities privately through GitHub private vulnerability reporting. Do not open a public issue.

Use the repository Security tab and choose **Report a vulnerability**:

https://github.com/kadima-tech/ubiquity-unify-feed/security/advisories/new

Describe the issue, the versions affected, and how to reproduce it. The report stays in a private security advisory while a fix is coordinated.
